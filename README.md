# New4 Optimized Pages

Bản tối giản cho GitHub Pages.

## Chạy local
```bash
npm install
npm run dev
```

## Deploy
- Đẩy lên repo `New4`
- Bật **Settings → Pages → GitHub Actions**

## Tài khoản admin
- admin@example.com
- Admin@123

## Ghi chú
Dữ liệu quản lý được lưu bằng `localStorage` để không cần backend khi chạy trên GitHub Pages.
